## 🔍 주요 발견 사항

### 1. 속도 차이 (예상 밖!)

**Large 모델이 Base Plus보다 1.9배 빠름!** 🚀

- Base Plus: 19초/프레임
- Large: 10초/프레임

**원인 분석:**
- Large 모델이 더 효율적인 아키텍처를 사용할 가능성
- 또는 GPU 최적화가 더 잘 되어 있을 수 있음
- 마스크 수가 적어서 후처리 시간이 줄어들었을 수도 있음

### 2. 마스크 검출 수

**Large 모델이 평균 12% 적은 마스크 검출**

- Base Plus: 평균 21개
- Large: 평균 18.4개

**해석:**
- Large 모델이 **더 큰 영역을 하나로 통합**하는 경향
- 과분할(over-segmentation)이 적음
- **보호장비 검출에는 유리할 수 있음** (큰 영역 선호)

### 3. VRAM 안정성

**Large 모델은 여유 공간이 매우 적음**

- Base Plus: 1.73 GB 여유 (안전)
- Large: 0.57 GB 여유 (위험)

**리스크:**
- 더 복잡한 이미지에서 OOM 가능성
- 다른 프로세스와 GPU 공유 시 문제 발생 가능

## 💡 결론 및 권장사항

### ✅ Large 모델 사용 시 장점

1. **처리 속도 1.9배 빠름** (예상 밖의 이점!)
2. **세밀한 부분 검출 우수** (손, 작은 장비)
3. **RTX 3070 8GB에서 작동 가능** (아슬아슬하지만 성공)

### ⚠️ Large 모델 사용 시 단점

1. **VRAM 여유 공간 매우 적음** (0.57 GB)
2. **OOM 위험** (복잡한 이미지, 고해상도)
3. **다른 프로세스와 GPU 공유 불가**

### 🎯 최종 권장사항

#### 포트폴리오 프로젝트 목적으로는:

**Large 모델 사용 권장** ✅

**이유:**
1. **더 빠른 처리 속도** → 데모 시연 시 유리
2. **세밀한 검출** → 시각적으로 더 인상적
3. **"Large 모델 사용"** → 이력서에 기술 스택으로 어필
4. **실제로 작동함** → RTX 3070에서 검증 완료

**주의사항:**
- 테스트 이미지는 1080x1920 이하로 유지
- 단일 프로세스로 실행 (다른 GPU 작업 동시 실행 금지)
- OOM 발생 시 Base Plus로 폴백 준비
